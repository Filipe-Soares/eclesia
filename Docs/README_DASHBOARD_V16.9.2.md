# v16.9.2 — Dashboard FINANCEIRO

- `/dashboard` agora aceita `ADMINISTRADOR` e `FINANCEIRO`.
- ADMINISTRADOR mantém a visão da v16.9.1.
- FINANCEIRO recebe template próprio com entradas, saídas, resultado, contribuições, contas vencidas, repasses vencidos e projetos/recursos.
- Organização limitada às organizações autorizadas do usuário.
- Período padrão: mês atual.
- Recursos vinculados/utilizados/saldo são derivados, sem campos de total persistidos.
- Alertas permanecem consultas derivadas; nenhuma tabela de dashboard/notificação foi criada.
- Nenhuma migration nesta versão.
